# Практична робота 7: Обробка та аналіз IoT-даних в openHAB

---
## 🤖 Декларація використання ШІ

- **Назва інструменту ШІ:** Gemini
- **Мета використання:** Генерація конфігурацій openHAB (`.items`, `.persist`, `.rules`, `.sitemap`), налаштування обробки RRD4j та вирішення помилок запуску середовища у Git Bash під Windows.
- **Текстовий запит (промпт):** *"Практична робота 7: Обробка та аналіз IoT-даних в openHAB... давай зробимо через гіт баш"*
- **Фрагменти згенерованого контенту:** Синтаксис Rules DSL (функції `averageSince`, `previousState`), конфігурація persistence RRD4j, структура Sitemap.
- **Опис власного доопрацювання:** 
  - Налаштовано шляхи до конфігурацій у Windows (`C:\openhab\conf`).
  - Усунуто конфлікт із відсутністю `JAVA_HOME` та `find.exe` під час запуску `./start.bat`.
  - Встановлено модуль `openhab-ui-basic` через Karaf Console (`feature:install openhab-ui-basic`).
  - Протестовано роботу симуляції, збереження в RRD4j та зроблено відеозвіт.
